




# Git 学习笔记

## Git 的作用

Git 用于记录文件的修改历史，方便版本回退和多人协作。

## 工作区、暂存区和本地仓库

- 工作区：实际编辑文件的地方。
- 暂存区：存放准备放入下一次提交的修改。
- 本地仓库：保存已经提交的版本记录。

## 常用命令

- git status：查看当前分支和文件修改、暂存情况。
- git add：将文件的当前修改加入暂存区。
- git commit：将暂存区的内容提交到本地仓库。

## Git 分支

### 什么是 Git 分支

分支是一条独立的开发路线，可以在分支上修改和提交代码，
合并前不会改变主分支的提交记录。

### 为什么使用分支

开发新功能或修复问题时，可以在独立分支完成修改，
检查通过后再合并到主分支，方便协作和管理。

### 创建并切换分支

git switch -c git-practice 表示创建 git-practice 分支并切换过去。
git checkout -b git-practice 也可以完成相同操作。

### 合并分支

git merge 用于将指定分支的开发成果合并到当前分支。
合并前需要先切换到接收修改的目标分支。

- docs: 添加 Git 练习笔记

## 分支创建和合并过程

使用 git switch -c git-practice 创建并切换到练习分支。
补充笔记并提交后，切回主分支，
使用 git merge git-practice 完成合并。

## .gitignore 规则

- node_modules/：忽略依赖目录。
- dist/：忽略构建输出目录。
- .env：忽略环境配置文件。
- *.log：忽略日志文件。
